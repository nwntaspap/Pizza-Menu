# Pizza Menu 🍕

My first project built with React!

A simple pizza menu application. The project focuses on learning the fundamentals of React, including components, props, JSX, and rendering dynamic data.

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

This project uses Vite as the development environment.

```bash
npm install
npm run dev
```

## Learning Goals

The main goal of this project is to gain hands-on experience with the core fundamentals of React and understand how to build user interfaces using reusable components.
